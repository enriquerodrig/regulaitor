- **D1 per-norma cap=2**: v0.1.11 mechanically demonstrated cross-corpus improvement; H10 cohort (which defines v0.1.20-bar) is NOT cross-corpus dominant so impact uncertain on bar metrics; cross-corpus cohorts (v0.1.13/v0.1.15) should benefit.

- **D3 chat refusal mock**: pure test addition; no production behavior change.

v0.1.22 paid run measures the cumulative impact.
