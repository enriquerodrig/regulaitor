### T2 — GREEN D1: fix transition matrix bug ($0, ~20 min)

**Input**: T1 RED tests
**Output**: transition matrix test GREEN
**File**: `scripts/v0120_compare.py` line 176–195

**Diagnosis**: The current `build_verdict_transition_matrix` iterates case_id but checks `if case_id in cases_by_id_b` BEFORE accessing. The problem is subtle: the code does check presence, but the actual bug is that the matrix is never populated correctly because the logic doesn't iterate the tuples correctly. Re-read the loop at lines 187–193:

```python
for case_id, case_a in cases_by_id_a.items():
    if case_id in cases_by_id_b:
        case_b = cases_by_id_b[case_id]
        v_a = case_a.actual_verdict
        v_b = case_b.actual_verdict
        if v_a in matrix and v_b in matrix[v_a]:
            matrix[v_a][v_b] += 1
```

This looks correct on first reading. The actual bug per spec D1 is that the condition `v_a in matrix and v_b in matrix[v_a]` is the culprit. If `v_a` is `"requires_human_review"` (or any verdict not in the initial matrix keys), it's skipped. The issue is that the matrix is initialized with keys `["pass", "RHR", "block"]` but `case_a.actual_verdict` may be `"requires_human_review"` (different string). Check what strings are used in the code: line 184 uses `verdicts = ["pass", "RHR", "block"]` but CaseMetrics expects values from the ChatCaseResult enum which uses `"requires_human_review"` (not `"RHR"`).

**Fix**: Normalize verdicts before matrix access:

```python
def build_verdict_transition_matrix(
    cases_a: list[CaseMetrics],
    cases_b: list[CaseMetrics],
) -> dict[str, dict[str, int]]:
    """Build a 3x3 transition matrix from ARM A verdicts to ARM B verdicts."""
    cases_by_id_a = {c.case_id: c for c in cases_a}
    cases_by_id_b = {c.case_id: c for c in cases_b}

    verdicts = ["pass", "requires_human_review", "block"]
    matrix = {v1: {v2: 0 for v2 in verdicts} for v1 in verdicts}

    for case_id, case_a in cases_by_id_a.items():
        if case_id in cases_by_id_b:
            case_b = cases_by_id_b[case_id]
            v_a = case_a.actual_verdict
            v_b = case_b.actual_verdict
            if v_a in matrix and v_b in matrix[v_a]:
                matrix[v_a][v_b] += 1

    return matrix
```
