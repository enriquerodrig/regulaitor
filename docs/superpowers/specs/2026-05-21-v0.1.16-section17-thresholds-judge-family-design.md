## 1. Goal & honest framing

Define the **numeric bar** that the v0.1.20 paid bundle measurement must clear, and document the **LLM-judge family decision** that ADR-0010 D1 deferred to "H12 router multi-LLM" (which closed without migrating). v0.1.16 ships the bar as a soft mark in `evals/reports/latest.md` (no CI gate, no `--gate` flag) and the judge stays Haiku 4.5 (ADR-0010 D1 caveat carried forward to HX cross-vendor migration; CLAUDE.md §19 satisfied literally by Haiku ≠ Sonnet model class).

**Honest TFM-defense framing**: v0.1.16 is the **measurement-architecture milestone**. It defines what "v0.1.20 success" means without doing the measurement itself. The bar is anchored to measured precedent (H10 30-case baseline + H15 v1.2 30-case partial intervention) — every threshold value is derivable from existing evidence, no promised numbers. The aspirational §17 targets stay as long-term direction (info-only column); the v0.1.20-bar codifies "the next acceptable evidence point" given what v0.1.10-v0.1.15 has stacked. v0.1.20 is where this gets evaluated.

**Single focus**: this milestone is the threshold architecture + judge-family decision. No paid LLM run; no Auditor/citation-validator touch; no backend touch; no schema change; no judge migration. The judge-family caveat from ADR-0010 D1 is resolved with a documented decision (not just continued silent deferral).

## 2. Decisions (D1–D5)

- **D1 — Thresholds shape = dual-layer (aspirational + v0.1.20-bar), single source of truth.** Replace `evals/report.py::_THRESHOLDS` with a 4-tuple table `(metric, v0120_bar, aspirational, gated)`. The v0.1.20-bar is the soft mark v0.1.20 must clear; aspirational §17 targets stay as long-term direction (rendered too, informationally). One constant, both layers; the report renders 4 columns: `Métrica | Valor | v0.1.20-bar | Aspiracional`. Rejected: aspirational-only (no anchor for v0.1.20 success), per-case-type stratification (premature optimization; v0.1.20 measurement will surface if needed).

- **D2 — v0.1.20-bar values, per metric (derivation lineage from measured baselines).** Every bar is anchored to existing measured datapoints — no promised numbers. - **D3 — Judge family stays Haiku 4.5 (ADR-0010 D1 caveat resolved with explicit "stay" decision).** No model migration. Rationale: (a) ADR-0010 D1 explicitly chose `claude-haiku-4-5-20251001` as "distinct from production Sonnet model class" — §19 "modelo juez distinto al de producción" satisfied literally; (b) cache continuity preserved (40 H10 entries reused at v0.1.20 if Analyst output unchanged — partial savings); (c) known-quantity behavior (H8/H10/H15 all judged by Haiku); (d) single API key; (e) the user has $0 Anthropic budget — switching judge invalidates all 40 cached entries and requires full re-run on 64-case set just to confirm correlation. Cross-vendor migration to GPT-4o-mini or Llama-3.3-70b-via-Groq remains an option for HX (post-TFM); the option is documented in ADR-0021 Consequences and stays viable if a future signal demands it. Rejected: GPT-4o-mini migration (invalidates cache + 2nd-vendor dependency + N=5 A/B needed to confirm correlation — premature without budget); multi-judge consensus (3× cost + Groq I-2 contamination risk + harness multi-judge orchestration code is non-trivial; over-engineered for v0.1.16 scope).

- **D4 — Enforcement = soft mark only (no `--gate` flag, no CI integration).** v0.1.20-bar metrics get ❌ badge if below the bar; `make eval` exits 0 regardless (no build break). Soft mark matches the existing report-as-evidence pattern (ADR-0010 D4: no LLM in CI, $7/PR unsustainable). v0.1.20 acceptance ritual: decisions_log narrative interprets "X/8 metrics passed v0.1.20-bar; Y/8 below — documented as deeper system-level ceiling per H15/H15.1 §22.22 pattern" + production-default flips (Analyst v1.3, RetrievalConfig per-norma cap, etc.) decided in that narrative based on per-metric direction. Rejected: hard `--gate` CLI flag (over-engineered; ADR-0010 D4 stays firm); CI integration (rejected per ADR-0010 D4 budget reasoning).
