### 2.2 Auditor paths (the 3 possibilities)

```
For each Finding:
  Finding-Lenient: any(r.validated for r in citations)  # STRICT 3-check (line 52)
  → 0 strict-valid → Finding "blocked"
  → ≥1 strict-valid → Finding "pass"

All Findings pass: all-pass branch
  → Tier 1 quorum: n_invalid_strict >= 2 → RHR; else PASS

All Findings blocked: all-blocked → BLOCK

Some pass + some blocked: partial → RHR (Strict-Answer)
```

Path A (all-pass + Tier 1 fires) = Tier 1 quorum is the gatekeeper.
Path B (partial → RHR) = Strict-Answer routing is the gatekeeper.
Path C (all-blocked → BLOCK) = Finding-Lenient is the gatekeeper.
