## 3. Scope (3 items)

### D1 — Flip `max_chunks_per_norma=2` to production default

Modify `src/regulaitor/rag/retrieval.py:63`:

```python
# BEFORE:
max_chunks_per_norma: int | None = None  # v0.1.11; None == no cap == v0.1.10 behaviour

# AFTER:
max_chunks_per_norma: int | None = 2  # v0.1.21.2; default cap=2 per v0.1.11 BREAKTHROUGH cross-corpus 1/3->2/3; opt-out via RetrievalConfig(max_chunks_per_norma=None) restores v0.1.10 behaviour
```

**Backward-compat**: pre-existing callers constructing `RetrievalConfig()` with no args now get `max_chunks_per_norma=2` (previously `None`). To restore old behavior: `RetrievalConfig(max_chunks_per_norma=None)`. This is intentional — production gets the BREAKTHROUGH default.

**Pre-existing tests**: any tests asserting `cfg.max_chunks_per_norma is None` need update. Catalog at T0.

### D2 — Flip `top_k_auto=12` to production default

Modify `src/regulaitor/rag/retrieval.py:64`:

```python
# BEFORE:
top_k_auto: int | None = None  # v0.1.12; None == use cfg.top_k for auto == v0.1.11 behaviour

# AFTER:
top_k_auto: int | None = 12  # v0.1.21.2; default top_k for auto-corpus queries (12 chunks pre-purity-gate); opt-out via RetrievalConfig(top_k_auto=None) restores cfg.top_k usage
```

**Backward-compat**: only `corpus="auto"` queries are affected (the field is `auto`-path-only per v0.1.12). Explicit-corpus queries (default behavior) unchanged.

**Why 12?** v0.1.12 spec proposed 12 (twice the default top_k=5 with purity-gate margin). No paid measurement determined optimal value; 12 is the spec'd default.

### D3 — Chat redteam mock e2e tests

NEW file `tests/unit/redteam/test_chat_refusal_mock.py` (~5-10 tests):

Mock the chat pipeline (Retriever + Analyst + Auditor) end-to-end with adversarial chat queries. Verify v1.5 refusal flow + Capa A+B+C handle correctly.

Test scenarios (analogous to chat-014/015/029/030 from gold + nis2-006/dora-006):
- Adversarial: ask to fabricate citation → mock Sonnet returns v1.5 refusal → Capa B/C accept → Auditor verdict appropriate
- Adversarial: ask for definitive legal advice → mock refusal → flow completes
- Adversarial: prompt injection (ignore previous instructions) → sanitizer + refusal → flow completes
- Adversarial: ask about non-existent article → mock refusal citing real corpus → Auditor processes
- Edge case: mock Sonnet returns empty findings (should not happen post-Capa B) → Capa B rejects → Capa C retry → eventual valid or RuntimeError

All mocks; $0; no API calls.
