## 1. Executive summary

v0.1.24.1 cross-version diagnostic confirmed **Path B (Strict-Answer partial-Findings routing) DOMINANT at 8/10 = 80%** for H1.C cases. v0.1.23 Design B failed because Tier 1 quorum NEVER FIRES on these cases (they route through partial-Findings branch upstream). v0.1.25 Design H D2 targets the empirical gatekeeper with the LOWEST §6 risk variant.

**Design H D2**: in the partial-Findings branch (lines 62-70 auditor.py), relax routing from "always RHR" to "PASS IF every blocked Finding has all-citations failed_check==3 (paraphrase-only); else RHR". Zero arbitrary thresholds; binary safety condition; preserves Finding-Lenient + Tier 1 + validator BYTE-EQUIVALENT (no change to those layers).

Expected verdict_match lift: ~+0.20-0.30 on H10 30-case (vs v0.1.22 baseline 0.30 → predicted ~0.50-0.60). PRE-MEASUREMENT prediction; T6 measures actual.

§6 invariant interpretive (ADR-0032): partial-routing softening operates on AGGREGATION POLICY (how to combine pass+blocked Findings into a turn verdict) NOT on FINDING-LEVEL VALIDATION (Finding-Lenient strict text-match unchanged) NOR on PER-CITATION VALIDATION (validator strict 3-check unchanged). True fabrications (failed_check 1 OR 2) still route to RHR; only paraphrase-only blocked Findings (failed_check==3 universally) allow PASS.

### 2.1 Why D2 specifically (post-3-round methodology)

- D1 (threshold-based 50% pass + most invalids check==3): REJECTED for arbitrary tunable threshold + concrete vulnerability (mixed fab+paraphrase case still PASSes)

NEW helper function in auditor.py:
```python
def _all_blocked_findings_paraphrase_only(
    finding_verdicts: list[Literal["pass", "blocked"]],
    per_finding_results: list[list[AuditResult]],
) -> bool:
    """v0.1.25 (ADR-0032 Design H D2): True iff every blocked Finding has
    all its invalid citations with failed_check==3 (paraphrase mismatch only).
    Used by partial-Findings routing to decide PASS vs RHR.

    Returns False if ANY blocked Finding has ANY invalid citation with
    failed_check==1 (article fabrication) or failed_check==2 (apartado
    fabrication) — those indicate true §6-relevant fabrication and must
    route to RHR per the pre-v0.1.25 behavior.

    Pre-v0.1.24 cached AuditResults have failed_check=None (Pydantic v2
    default); those are treated as 'unknown' and the function returns
    False (conservative; preserves pre-v0.1.25 routing for legacy data).
    """
    blocked_indices = [i for i, v in enumerate(finding_verdicts) if v == "blocked"]
    for i in blocked_indices:
        for r in per_finding_results[i]:
            if r.validated:
                continue  # pass-citations don't count for blocked-Finding analysis
            if r.failed_check != 3:
                return False  # any non-Check-3 invalid → fabrication evidence
    return True
```
